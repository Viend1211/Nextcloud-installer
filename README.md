# Nextcloud Installer & Manager для Proxmox VE

## v0.4.4 RU

Добавлен мастер безопасного отключения старого диска после миграции Nextcloud.

### Новый пункт

```text
Управление дисками
└── Безопасно отключить старый диск после миграции
```
## Быстрый запуск

Запускать на самом хосте Proxmox от `root`:

```bash
rm -rf /tmp/nextcloud-installer /tmp/nextcloud-install.sh && \
curl -fsSL "https://raw.githubusercontent.com/Viend1211/Nextcloud-installer/main/install.sh?nocache=$(date +%s)" \
-o /tmp/nextcloud-install.sh && \
grep VERSION /tmp/nextcloud-install.sh && \
bash /tmp/nextcloud-install.sh


### Новый пункт

Мастер проверяет:

1. Контейнер Nextcloud запущен.
2. `occ status` работает.
3. Выбранный диск не является системным диском Proxmox.
4. Диск не входит в ZFS pool.
5. Диск не входит в mdadm RAID.
6. Диск больше не используется ни одним LXC.
7. Проверяются точки монтирования.
8. Проверяются записи `/etc/fstab`.

Если остались старые mount/fstab-записи, мастер предлагает удалить только эти подключения. Перед изменением `/etc/fstab` автоматически создаётся резервная копия.

После успешных проверок доступны три варианта:

```text
1. Оставить диск нетронутым
2. Подготовить к физическому отключению
3. Полностью очистить диск
```

Для полной очистки требуется ещё одно подтверждение и точный ввод имени диска.

### Рекомендуемый порядок после перехода на RAID1

```text
Миграция завершена
→ проверить Nextcloud
→ проверить zpool status / mdadm
→ Безопасно отключить старый диск
→ выбрать "Подготовить к физическому отключению"
→ выключить сервер
→ физически снять диск
```

Не рекомендуется очищать старый диск сразу после миграции. Лучше сначала некоторое время оставить его как аварийную копию.
