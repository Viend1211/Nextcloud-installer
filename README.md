# Nextcloud Installer & Manager для Proxmox VE

## Версия 0.4.0 RU

Основные настройки переведены на русский язык и выполняются через меню.

### Главное меню
- Установить новый Nextcloud
- Настроить существующую установку
- Диагностика Proxmox и хранилищ

### Управление дисками
Мастер сам предлагает выбрать контейнер, текущее хранилище и новый физический диск. Через меню доступны:
- добавить новый диск;
- заменить текущий диск на больший без RAID;
- перейти на два новых диска RAID1;
- выбрать ZFS Mirror или mdadm RAID1;
- добавить диск как Proxmox Storage;
- увеличить rootfs LXC;
- посмотреть варианты модернизации.

Старый диск при безопасной замене автоматически не стирается.

### Домены и внешний доступ
Через меню:
- показать trusted_domains;
- автоматически определить внешний IPv4;
- добавить IP;
- добавить домен;
- удалить запись.

Ручные команды OCC для этих обычных операций больше не нужны.

### Управление LXC
Через меню:
- консоль;
- сброс root-пароля;
- IP;
- конфигурация;
- использование дисков;
- запуск, остановка и перезапуск.

### Запуск
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Viend1211/Nextcloud-installer/main/install.sh)"
```

Перед форматированием всегда сверяйте размер, MODEL и SERIAL выбранного диска.
