# Nextcloud Installer & Manager для Proxmox VE

## v0.4.1 RU

Версия с единым русским интерфейсом, анимированным логотипом и отображением хода долгих операций.

### Что изменено

- Анимированный ASCII-логотип при запуске установщика и менеджера дисков.
- Для RAID1 больше не требуется вводить `CREATE RAID1`.
- Перед очисткой двух новых дисков появляется окно с кнопками:
  - `СОЗДАТЬ RAID1`
  - `НАЗАД`
- На экране показывается текущий этап и общий процент выполнения.
- Для `rsync` отображается реальный прогресс передачи данных.
- Ошибки показываются по-русски с реальным текущим этапом и последними 50 строками лога.
- Старый исходный data-диск при миграции не очищается автоматически.
- Добавлены визуальные этапы для:
  - замены data-диска на больший без RAID;
  - перехода на два новых диска RAID1;
  - ZFS Mirror;
  - mdadm RAID1.

### Запуск из GitHub

После замены файлов в репозитории:

```bash
rm -rf /tmp/nextcloud-installer /tmp/nextcloud-install.sh
curl -fsSL "https://raw.githubusercontent.com/Viend1211/Nextcloud-installer/main/install.sh?nocache=$(date +%s)" -o /tmp/nextcloud-install.sh
grep VERSION /tmp/nextcloud-install.sh
bash /tmp/nextcloud-install.sh
```

Перед операциями с дисками всегда сверяйте модель, объём и SERIAL. RAID1 не заменяет резервную копию.
